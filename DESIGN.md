# Diseño de producto — 21K Progress

## Idea visual

Un tablero deportivo editorial, limpio y orientado a progreso. Fondo neutro, superficies blancas/oscuras, números grandes, pocos colores semánticos y alta legibilidad móvil.

## Tokens

- Azul: volumen y métricas generales.
- Verde: progreso y ritmo.
- Naranja: fondo.
- Violeta: fuerza/carga.
- Gris: recuperación/neutral.
- Radio base: 16–20 px.
- Sombras discretas.

## Jerarquía de inicio

1. 21,1 km / mayor fondo / semana / ritmo reciente.
2. Kilómetros semanales + Camino a 21K.
3. Fondo semanal + evolución del ritmo.
4. Carga + insights.
5. Últimos entrenamientos.

## Mobile

- Bottom navigation de seis destinos.
- Métricas en 2 columnas.
- Gráficos apilados a una columna.
- Formularios en una columna.
- Modal de registro optimizado para pulgar.
